# Documentacao historica

Os arquivos deste diretorio registram implementacoes, analises, empacotamentos e
estruturas antigas do Sentinel. Eles sao preservados para consulta e auditoria,
mas nao devem ser usados como instrucao operacional atual.

As referencias vigentes sao o `README.md` da raiz e o indice em
`docs/README.md`.
